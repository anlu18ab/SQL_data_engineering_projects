# Data Engineering Projects
Hands-on projects to reinforce core data engineering concepts from the SQL for Data Engineering course held by Luke Barousse.

## Data Projects
### [1_EDA](1_EDA) - Exploratory Data Analysis
SQL-driven analysis of data engineer job market trends in Denmark, Sweden, and Norway using advanced querying techniques.

Skills: Complex joins, aggregations, analytical functions, data quality validation

### [2_DW_Mart_Build](2_DW_Mart_Build) - Data Pipeline - Data Warehouse and Mart
End-to-end ETL pipeline transforming raw CSV files into a star schema data warehouse and analytical data marts.

Skills: Dimensional modeling, ETL pipeline development, data mart architecture, production practices
